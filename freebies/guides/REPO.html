₹200 AdBlock chip: ESP32-C3 Adblock

Repo: M-Abozaid/esp32-c3-adblock. Ye Pi-hole jaisa DNS blocker hai jo ad domains ki request ghar ke network pe hi rok deta hai.

  • ESP32-C3 SuperMini board (online lagbhag ₹150–350)
  • USB-C data cable aur ek laptop
  • Router ka admin login (DNS setting badalne ke liye)
  1. Laptop pe VS Code aur PlatformIO extension install karo.
  2. GitHub se repo download karo aur PlatformIO mein folder kholo.
  3. README ke hisaab se apna WiFi naam aur password config mein daalo.
  4. Board USB se lagao aur Upload dabao (firmware flash hoga).
  5. Board ko router ke USB ya kisi charger se power do; README se uska IP address note karo.
  6. Router ki DNS setting mein wo IP daalo aur save karo. Ab ghar ke har device pe ad domains block honge.
⚠️ Limits (sach): YouTube aur Instagram ke ads nahi rukte, kyunki wo usi server se aate hain jisse video. Board band hua to internet DNS ki wajah se ruk sakta hai; router mein backup DNS rakho. Exact steps aur supported features repo ke README se confirm karo.

GitHub repos chalane se pehle

  • Owner check karo: naam copy karne wale fake repos bhi hote hain; official org ya jaana-maana developer ho.
