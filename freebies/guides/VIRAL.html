4 patterns

4 patterns jo farak laaye

  1. Pehle 3 seconds mein screen pe kuch zabardast ho. Title card, logo fade ya "Hi guys" nahi. Ek event jo aankh ignore na kar sake.
  2. Darshak ka Instagram dikhao, apna tool nahi. Jo cheez wo roz dekhte hain, wahi screen pe ho.
  3. Har line pe ek visual. Koi frame khaali ya static nahi.
  4. Comment karne ki ek wajah. Keyword + kuch value jo DM mein milegi.
Install

Install

Claude (claude.ai ya desktop app):

  1. GitHub repo kholo → green Code button → Download ZIP.
  2. Sirf virality folder ko zip karo.
  3. Claude mein Settings → Capabilities → Skills mein jao aur zip upload karo. Skill on karo.

Claude Code:

Terminal
git clone https://github.com/Ootto-AI/claude-virality-skill
cp -r claude-virality-skill/virality ~/.claude/skills/
💡 Optional: apni reels Claude ko seedha padhwani ho to Ootto connector se Instagram connect kar sakte ho (Settings → Connectors → Add custom connector). Bina connector ke bhi chalega: apni reels ke links ya screenshots paste karo.
