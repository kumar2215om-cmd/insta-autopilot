Kya milega

Setup se kya hoga

Is setup se Claude aapke YouTube channel ki videos aur views padhta hai, aur agle hafte ke titles, hooks, descriptions aur schedule ka draft banata hai. Final "yes" hamesha aapka: bina approval kuch post mat hone do.

⚠️ Ye setup ek third-party service (Uplika) ke through hai. Use karne se pehle unki pricing aur terms khud check karo.
Setup

Setup (5 minute)

  1. claude.ai kholo aur left menu mein Customize pe jao.
  2. Connectors tab kholo, phir Add custom connector dabao.
  3. Name: Uplika. Remote MCP server URL: Uplika ki website pe diya hua link paste karo (sirf official site se lo).
  4. Add, phir Connect dabao. Uplika mein sign in karo.
  5. YouTube chuno, apna channel select karo, permissions padho, phir Allow.
  6. Connectors list mein Uplika ke saamne Connected dikhe, to setup done.
💡 Custom connectors har Claude plan pe available nahi ho sakte; agar option na dikhe to apna plan check karo.
Prompt

Ready-made prompt

Neeche wala prompt copy karke Claude mein paste karo. Pehle confirm karo ki Claude bole "Connected to Uplika". Brackets wali jagah apni details bharo.

Copy karo
Tum mere YouTube channel ke manager ho. Channel: [channel name], niche: [topic], audience: [kaun dekhta hai], language: [Hinglish/Hindi/English].

1. Mere last 30 videos aur unke views, watch time padho. Top 5 aur bottom 5 videos batao, aur unme kya fark hai.
2. Mere niche mein abhi jo Shorts chal rahe hain, unke 5 patterns batao (hook style, length, topic).
3. Agle 7 din ke liye 7 upload ideas do. Har ek ke liye: title (60 characters se kam), pehle 3 second ka hook, description (keywords ke saath), aur best posting time.
4. Meri purani videos mein se 5 kamzor titles chuno aur better titles suggest karo. Badlav khud mat karna.
5. Pending comments ke liye reply drafts likho, mere tone mein. Post mat karna.

Rules: kuch bhi publish, schedule ya edit karne se pehle mujhse "yes" lo. Har jawab table mein do.

Safety

Safety: channel ki chaabi sambhal ke

Aap ek third-party app ko apne channel ka access de rahe ho, to ye 4 cheezein zaroor karo.

  • Permissions padho: Allow se pehle dekho app kya kar sakta hai (videos edit, comments post, upload).
  • Approval rule: prompt mein likha hai ki bina "yes" kuch publish na ho. Ise kabhi mat hatao.
  • Auto-replies pe nazar: AI replies kabhi galat ya robotic lag sakte hain; post hone se pehle padho.
  • Access hatana ho to: Google account → Security → "Third-party apps with account access" se Uplika remove karo. Claude mein bhi Customize → Connectors se disconnect karo.
