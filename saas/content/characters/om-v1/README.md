# Om's carousel character, v1

60 cut-out poses (transparent PNG) from Om's character sheets 1 and 3 (`source-sheet1.webp`, `source-sheet3.webp`, 1254×1254,
6×5 grids). File names are `sheet<N>-r<row>c<col>.png` (grid position on the source sheet).
Sheet 2 was left out (irregular grid; its poses repeat sheets 1 and 3).

**Low resolution:** each pose is only about 200 px wide (the source sheets are small). Fine for layout work; for posting,
upscale them or replace them with Om's high-resolution versions of the poses used most.
