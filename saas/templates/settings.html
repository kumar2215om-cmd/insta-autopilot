Google Sheets in 2 minutes
  1. Open a new Google Sheet → Extensions → Apps Script.
  2. Paste this, then Deploy → New deployment → Web app → "Who has access: Anyone" → Deploy, and copy the URL: 
    function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  SpreadsheetApp.getActiveSheet().appendRow([d.at, d.event, d.username, d.email || "", d.phone || "", d.automation || ""]);
  return ContentService.createTextOutput("ok");
}
  3. Paste the URL above, tick the box, Save, then "Send a test lead". A row appears in your sheet.

Each lead is sent as JSON: event (lead / follow / test), account, at, username, email, phone, automation.
