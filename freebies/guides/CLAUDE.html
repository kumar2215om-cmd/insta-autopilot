13 free Claude skills that run your Instagram

Good to know

What claude-ig is

Repo: github.com/nicojunk/claude-ig

⚠️ This runs in Claude Code (Anthropic's terminal app), not the normal Claude chat app. The writing skills (reels, hooks, captions, carousels, stories, calendar) work right away. Live analytics (/ig analyze, and live competitor scraping) need an Instagram Graph API token or an Apify token. Apify has a free tier.
Step 1

Install Claude Code

Follow the official guide: docs.anthropic.com → Claude Code. You need a Claude Pro/Max plan or an API account.

Step 2

Install the skills

Mac / Linux (one command)
curl -fsSL https://raw.githubusercontent.com/nicojunk/claude-ig/main/install.sh | bash
Or manually
git clone https://github.com/nicojunk/claude-ig.git
cd claude-ig
chmod +x install.sh && ./install.sh
💡 Then restart Claude Code. On Windows, run the commands inside WSL.
Step 3

Use the commands

CommandWhat it does
/ig reel <topic>Full reel: hook, script, caption, thumbnail
/ig hook <topic>Writes hooks and scores them
/ig caption <topic>Optimised caption with a save CTA
/ig story <topic>Story sequence (slides, stickers, polls)
/ig carousel <topic>Carousel: cover, slides, CTA
/ig competitor <accounts>What's working for competitors in your niche
/ig auditFull content audit with a 100-point score
/ig calendar weeklyWeekly or monthly content calendar
/ig strategyPositioning and content strategy
/ig commentComment reply strategy
/ig repurpose <post>Repurpose for other platforms
/ig affiliate <partner>Compliant affiliate content
/ig analyze <post-url>Post performance (needs an API token)

export INSTAGRAM_ACCESS_TOKEN="your-token"

pip install -r requirements.txt   # Python 3.12+
Routine

A simple daily routine

  1. /ig competitor @acc1 @acc2: spot what's trending in your niche.
  2. /ig reel <that topic>: get the hook, script, caption and thumbnail.
  3. Record or edit, then post.
  4. Once a week, run /ig audit and /ig calendar weekly.
💡 Always read and personalise the output before posting. It's a strong first draft, not a replacement for your voice.
