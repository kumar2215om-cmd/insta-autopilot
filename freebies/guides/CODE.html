Code se reels, credits ke bina

Tumne CODE comment kiya tha, to ye rahi saari details. 🙌 Mere page ki reels kisi AI video model se nahi bantin. Ye code se bantin hain, ek free framework Remotion ke saath. Claude Code wo code likhta hai: scenes, animations, captions, SFX. Phir Remotion usse MP4 render karta hai.

No credits kyun? AI video tools har video ke credits kaatte hain. Yahan video tumhare computer pe render hoti hai, isliye per-reel cost ₹0 hai aur style bhi koi bhi ho sakta hai.

⚠️ Honest catches: Claude Code ke liye Claude ka paid plan chahiye. Remotion individuals aur chhoti teams ke liye free hai; badi companies ko company license lena padta hai (remotion.dev pe check karo). Voiceover ElevenLabs (ya koi TTS) se aata hai; Remotion voice nahi banata.
Setup

Setup (ek baar, ~20 min)

  1. Node.js install karo (nodejs.org se, LTS version).
  2. Claude Code install karo. Steps Anthropic ki docs mein hain (docs.claude.com → Claude Code).
  3. Naya Remotion project banao (neeche wala command).
  4. Us folder mein terminal kholo aur claude likho. Claude Code shuru ho jayega.
  5. Remotion skill: Remotion ki official docs mein AI / Claude Code wala section hai. Wahan unka agent skill install karne ka command milega. Usse Claude ko Remotion ke best practices pata rehte hain, aur reels zyada clean banti hain.

Apna voiceover public/vo.mp3 mein daalo, phir Claude Code ko ye do:

Phir har line ke liye ek scene banao:
- Upar bada headline (2-5 words), payoff word alag color mein
- Beech mein ek hi visual (window card, chart, ya icons)
- Neeche karaoke caption pill (max 5 words, bole gaye words dark)

- Halka background music, voice ke neeche
Style: [cream bg + blue/pink accents]  (ya jo style chahiye)
Render se pehle 12 key frames ki stills dikhao.

Style ideas (prompt mein Style: badal do):

  • Cream + serif headlines (clean, premium)
  • Dark terminal / code look (tech)
  • Pixel-game (Silkscreen font, retro)
  • Bold neon + glass cards
Quality

Reels bekaar na lagen: quality tips

  • Ek frame, ek idea: headline + ek visual + caption, bas. Zyada text = clutter.
  • Hook pehle 1 second mein: pehle frame pe hi payoff dikhao.
  • Stills check karo: render se pehle frames dekho. Kuch overlap ya cut ho raha ho to Claude ko bolo theek kare.
  • Viral reel ka structure seekho: kisi viral reel ke hook, beats aur CTA ko frame by frame samjho, phir apna content usi structure mein daalo. Copy nahi karna.
  • Sound: har pop/transition pe SFX + halka music. Final audio -14 LUFS rakho.
  • Lambai: 30-50 sec. Pauses kaat do.
  • Sach bolo: jo numbers ya claims verify nahi hote, wo mat daalo.
