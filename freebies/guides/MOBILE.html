Before you start

Honest note

⚠️ The Code tab (Claude Code cloud sessions) needs a paid plan (Pro or Max). If you don't see the Code tab, your plan doesn't include it, so use the free jugaad at the bottom.
Setup

One-time setup

  1. Install the Claude app (iOS / Android) and log in.
  2. Make a free GitHub account and create a repo (e.g. my-reels). This is where your videos and code get saved.
  3. In the Claude app, open the Code tab, then connect GitHub when it asks and pick your repo.
  4. Environment: keep Default.
Every time

Make a video (every time)

  1. Open Code → pick your repo → type or hold the mic and say what you want.
  2. Paste the prompt below (edit the song and style).
  3. Lock your phone. It runs in Claude's cloud, so you can come back later.
  4. When it's done, open the repo (GitHub app or website) → out/video.mp4 → download → post.
Prompt
Make a 1080x1920 vertical lyric video for Instagram using Remotion.
Song lyrics (one line per caption): [PASTE LYRICS]
Style: dark night sky, thin neon line-art city skyline that draws itself, soft glow, handwritten-style text that fades in word by word, gentle camera drift.
Length: [15-30] seconds, 30 fps. Add my audio file [audio.mp3] if I uploaded it to the repo, otherwise no audio.
Render the final MP4 to out/video.mp4, commit it to the repo, and tell me when it's done.
💡 Only use songs you have the rights to use, or add the music inside Instagram from its library.
Free jugaad

Free plan jugaad (no Code tab)

  1. Open a normal chat in the Claude app.
  2. Paste the prompt below.
  3. Open the artifact full screen → start your phone's screen recording → crop it in the gallery or CapCut → add music → post.
  4. Quality is a bit lower than a real render, but it works.
Jugaad prompt
Create an artifact: a full-screen animated lyric video in HTML/CSS/JS, vertical 9:16.
Lyrics: [PASTE LYRICS]
Style: dark night sky, neon line-art skyline that draws itself, words fade in one by one, loops smoothly. No sound needed. Make it start automatically.
