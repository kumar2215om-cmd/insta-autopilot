The idea

One agent, many playbooks

This works best in Claude (Projects), and also works in ChatGPT (Projects or custom GPTs). The idea: stop building a new agent for every task. Run one agent and give it a playbook for each job.

Anthropic engineers made the same point in their talk "Don't build agents, build skills instead". A playbook is basically a skill: written instructions plus files the AI loads when it does that job.

Setup

Setup (one time)

In Claude, create a Project called "My Delegation" with three parts:

  • PLAYBOOKS: one file per job (e.g. weekly-report.md)
  • TOOLBOX: approved scripts, templates, docs and examples
  • Project instructions: the master prompt below
Master prompt
You are my delegate. Before any task:
1. Find the matching playbook and follow it exactly.
2. Use files from the toolbox instead of creating new versions.
3. Before you show me anything, check your work against the playbook's DONE MEANS checklist and tell me which checks passed.
If no playbook exists for a task, say so and offer to interview me to create one.
01 · Interview

Turn your work into a playbook

Interview prompt
Interview me about how I do <task> until you could do it without me.
Ask one question at a time: the goal, who it's for, the inputs, the steps, the format, the rules, common mistakes, and who signs it off.
When you have enough, say "READY".
Then
Turn everything I told you into a playbook file:
# <Task name>
Goal:
Inputs:
Steps (numbered):
Rules (always / never):
Toolbox files to use:
DONE MEANS (checklist):
Keep it under one page.
Save it in PLAYBOOKS.
02 · Toolbox

Never make the same thing twice

Every time you approve an output (a script, a template, an email or a report), save it to the toolbox and link it in the playbook as a rule.

Toolbox prompt
This output is approved. Turn it into a reusable template (replace specifics with {placeholders}).
Then add a rule to the <task> playbook: "Always start from toolbox/<file>".
03 · Proof

The "done" checklist

Hardly anyone does this, and it's the step that makes the agent reliable.

Checklist prompt
Write a DONE MEANS checklist for <task>: 4–6 checks that are specific and verifiable (no "looks good").
Add it to the playbook. From now on, review your own work against it before you hand anything over, and show me pass/fail for each check.

Example for a weekly report:

  • Matches the brief
  • Built from the toolbox template
  • Every number double-checked against the source
  • Ready to send as is
04 · Fix loop

The fix loop

When the agent messes up, don't correct it in the chat, because the chat is forgotten next time. Fix the playbook instead:

Fix prompt
That was wrong because <reason>.
Update the <task> playbook so this can't happen again (add a step, a rule or a check). Show me the diff.
💡 Playbook → run → check → fix playbook. That's the whole loop. Each fix makes every future run better.

Starter playbook ideas: weekly report · client emails · reel scripts · meeting notes to action items · invoice follow-ups · social captions · research summaries.
