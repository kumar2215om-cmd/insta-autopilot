Character image nahi, code hai

Ye character SVG code se bana hai: circles, curves aur rang. Isliye:

  • Kabhi blur nahi: vector hai, har size pe sharp.
  • Rang = ek line: skin, shirt, baal sab LOOKS mein.
  • Expressions = props: eyes: wink, mouth: open, wahi character.
  • Haath sach mein mudte hain: hum sirf haath ki jagah batate hain, code khud elbow nikaalta hai (2-bone IK). Wave, point, namaste: sab natural.

prompt

Claude Code se apna banao

Claude Code prompt (kit folder mein)
Make my own presenter character from src/Character.tsx (pure SVG, keep the IK arms).
My character: [person / animal / object], look: [skin, hair, outfit colours], signature detail: [glasses / cap / earrings…], label on shirt: [@handle].
Expressions I need: [happy, thinking, surprised, wink]. Actions in my reel: [wave at 0s, point at 3.2s, namaste at 9s…].
1. Read README.md and src/ first. Add my look to LOOKS and any new detail as SVG shapes in the head group (no images).
2. Keep the 2-bone IK arms; set poses by hand positions only.
3. Render one still per action + one per expression, look at them yourself (elbows bending the natural way, hands not hiding the face, nothing outside the frame), fix, then show me.
4. Export a 1080×1080 head-and-shoulders PNG for my profile picture.
💡 Pehli baar 100% perfect nahi aayega. Still dekh ke seedha bolo: "aankhein badi karo", "chashma jodo", "smile thodi chhoti". 2–3 rounds.
poses

Pose kaise likhte hain

src/Demo.tsx
[0,   {l: [148, 668], r: [500, 215], wave: true}],              // wave
[2.4, {l: [80, 150],  r: [520, 150], jump: 1, mouth: 'open'}],  // dono haath upar + jump
[3.6, {l: [148, 668], r: [470, 175], point: 'r', eyes: 'wink'}], // point + wink
[4.8, {l: [286, 445], r: [314, 445], bow: 6}],                  // namaste

l / r = haath kahan ho (600×780 box mein). Elbow code khud set karta hai, poses 0.3 sec mein blend hote hain.

brand

Character ko brand banao

  • Har reel mein same character: log chehra yaad rakhte hain.
  • Ek signature detail jo kabhi na badle.
  • Expressions kaam se do: twist pe shocked, payoff pe khush.
  • Profile picture bhi wahi: head-and-shoulders crop ko DP banao.
  • Design lock karo: set ho jaaye to Claude ko bolo "is look ko LOOKS mein lock karo, aage mat badalna".
