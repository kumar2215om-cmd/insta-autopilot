raaz

Video = photos ki line

Reel mein 30 photos har second hoti hain (30 fps). 6 second = 180 photos. Animation bas itna hai: har photo mein cheez thodi alag jagah, size ya opacity pe.

  1. Har frame ek web page: Remotion mein scene React se likhte ho. Page ko pata hota hai "abhi kaunsa second hai".
  2. Browser screenshot leta hai: frame 0, 1, 2… har ek ka.
  3. FFmpeg jodta hai: saari photos + awaaz = MP4.
poora animation, 2 line mein
const t = useCurrentFrame() / 30;           // abhi kaunsa second
const pop = spring({frame: (t - 0.6) * 30, fps: 30}); // 0.6s pe uchhal ke aao

Same code, sirf time badalta hai. Isliye result har baar same: koi random glitch nahi.

claude code

Apna banao, Claude se

Claude Code prompt (kit folder mein)
Make this Reel Motion Kit mine.
Brand: background [#…], cards [#…], text [#…], accent [#…], accent2 [#…], font [Google font], radius [px], handle [@…].
Scenes: [hook with a big number → 3 tips one by one → comment CTA].
Voice: [public/vo.wav + captions.json from Caption Sync Kit, OR "no voice, time it in seconds"].
1. Add my brand as a new preset in src/brand.ts; never hard-code colours.
2. Build my scenes as a copy of src/Demo.tsx using only the blocks in src/motion.tsx; all times in the T timeline.
3. Keep text, numbers and faces inside SAFE.
4. Render stills of each beat with debugSafeZones on and off, check them yourself, fix overflow/overlap/contrast, show me.
5. After I say ok, render the MP4.
💡 Stills dekh ke seedha bolo: "number bada karo", "stamp thoda upar", "tip 2 jaldi aaye". 2–3 rounds mein look set.
