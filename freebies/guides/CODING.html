1 · Supabase

1 · Supabase (official)

Connects Claude straight to your Supabase project: run SQL, apply migrations, generate TypeScript types, and check security and performance advisors, without opening the dashboard.

Easiest: open /plugin in Claude Code, browse the official marketplace, and install supabase. Or add the Supabase MCP server: see supabase.com/docs/guides/getting-started/mcp

⚠️ Start in read-only mode and on a dev project, not production.
2 · Vercel

2 · Vercel (official)

Say "deploy my app" and Claude builds and ships it to a preview or production URL, all from the terminal.

Open /plugin and install vercel from the official marketplace, or use Vercel's MCP: vercel.com/docs/mcp. You'll log in to Vercel once.

3 · oh-my-claudecode

3 · oh-my-claudecode

Turns Claude into a team of specialized agents. Type team and they plan, write the PRD, build, verify and fix together. There's also autopilot and parallel "ultrawork" modes.

Repo: github.com/Yeachan-Heo/oh-my-claudecode

Install
/plugin marketplace add Yeachan-Heo/oh-my-claudecode

Then install it from that marketplace and run its setup command (see the README).

💡 Team features use Claude Code's experimental agent-teams setting, and they use more tokens.
4 · Chrome DevTools

4 · Chrome DevTools MCP (by Google's Chrome team)

Gives Claude eyes on a real Chrome browser: it reads console errors, inspects network requests, takes screenshots and runs performance traces, instead of coding blindfolded.

Repo: github.com/ChromeDevTools/chrome-devtools-mcp

Install (in your terminal)
claude mcp add chrome-devtools -- npx chrome-devtools-mcp@latest
Try
Open localhost:3000, check the console and network for errors, and fix them.
Workflow

Suggested workflow

  1. Build with oh-my-claudecode's team.
  2. Debug in the real browser with Chrome DevTools MCP.
  3. Manage the database with Supabase.
  4. Ship with Vercel.
