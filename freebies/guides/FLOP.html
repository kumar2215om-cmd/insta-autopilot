Ye kya hai

Ye doc kya hai?

Tumne reel pe FLOP comment kiya tha, to ye raha poora setup. 🙌 Claude ko apne Instagram se connect karo, phir pucho "meri last reel flop kyun hui?". Claude tumhari asli reels padhta hai, retention batata hai (kitne log pehle 5 sec mein chale gaye), fix suggest karta hai, aur agli script bhi likh deta hai.

⚠️ Honest note: Ye connection Ootto naam ke third-party connector se hota hai, Claude ka official Instagram feature nahi hai. Connect karne se pehle permissions padho. Reel mein dikhaya 31% sirf ek example hai, tumhara number alag hoga. Koi bhi reel post karne se pehle khud review karo.
Step 1

Connector add karo (sirf ek baar)

  1. claude.ai kholo (desktop/browser pe best).
  2. Settings → Connectors mein jao.
  3. Add custom connector pe click karo.
  4. Name mein likho: Ootto
  5. Remote MCP server URL mein Ootto ka MCP link paste karo. Ye link Ootto ki website/dashboard pe milta hai. Hamesha official site se hi copy karo, kisi random DM ya comment se nahi.
  6. Add dabao → Connect → Ootto mein sign in karo → apna Instagram account choose karo → Allow.
  7. Connectors list mein Ootto ✓ Connected dikhna chahiye. Bas, setup done! ✅
💡 Custom connectors kuch plans pe hi available hote hain. Option nahi dikh raha to apna Claude plan aur settings check karo.
Step 2

Pucho "flop kyun hui?"

Naya chat kholo, check karo ki Ootto connected hai, aur ye prompt copy-paste karo:

Copy karo
Ootto connector se meri Instagram profile ki last 12 reels padho.
Meri sabse latest reel ka analysis karo aur batao:
1. Retention: pehle 3 aur 5 second mein kitne % log chale gaye?
2. Flop ki top 3 wajah (hook, pacing, payoff, caption, topic).
3. Meri best-performing reel se compare karo: usme kya alag tha?
4. Har problem ka ek clear fix, simple Hinglish mein.
Jo data connector se nahi mil raha, wo saaf batao. Guess mat karo.
  • Retention ka breakdown (jaise: "31% log pehle 5 sec mein gaye")
  • Flop ki wajah, tumhari hi reels ke data se
  • Ek seedha fix, jaise "payoff ko frame 0 pe dikhao"
Uske baad

Follow-up prompts

Agli script likhwao
Is analysis ke basis pe meri agli reel ki script likho.
Hook pehle 1 second mein, payoff frame 0 pe dikhe.
Format: timestamp + line (0.0s, 1.4s, 4s...), 30-40 sec, Hinglish.
Reel banwao (Ootto)
Is script se Ootto ke through reel bana do. Mere pichhle reels jaisa style rakho.
Apni footage edit karwao
Ye meri raw footage hai. Dead air aur lambe pauses kaat do, aur hook ko shuru mein laao.
💡 Done-for-you mode: Ootto mein ye mode on karne pe wo tumhari reels se seekhta hai, trending research karta hai, idea banata hai, aur finished reels tumhe bhejta hai. Post tum khud karo, har reel pehle dekh ke. Ye Ootto ka feature hai: kya available hai aur kitne ka hai, unki site pe check karo.
