Step 2 · Master prompt: apni reel factory

Ye prompt ek baar chalao. Claude poora project banata hai aur jo seekhta hai wo ek skill file mein save karta hai, taaki agli baar bas "reel banao: [topic]" bolna pade. Brackets apne hisaab se bharo: apna style banao, kisi ka copy nahi.

master prompt · Claude Code mein paste karo
Set up a reel factory in this folder: Remotion, 1080×1920, 30 fps, vertical Hinglish explainer reels.

MY STYLE (fill in)
- Presenter: [none / code-drawn 2D character / my AI avatar image public/avatar.png]
- Look: background [#…], ink [#…], accent 1 [#…], accent 2 [#…], font [Google font]. Keep all of it in one brand file.
- Captions: [word-by-word, bottom-centre, keywords in accent boxes]
- Handle: [@yourhandle]

BUILD
1. Scene building blocks: section (Beat), spring pop-in, stamp, card, count-up number, typing text, mouse cursor click, beat zoom.
2. Word-timed captions from my script + the voice file (use the voice's pauses to place each script line; never let captions misspell my words).
3. Sound: whoosh on section changes, pops on pop-ins, impact on stamps, a quiet music bed that ducks under the voice.
4. One render command: video → loudness −14 LUFS → cut silences → 1.1x → a contact sheet of frames.
5. A cover image (1080×1920, key text inside the 3:4 grid crop).

RULES
Text never overlaps the presenter or captions; keep everything inside Instagram safe zones (top ~220px, bottom ~380px, right ~120px). Something new every 2–3 seconds. Reels under 50 seconds.

Then make a 15-second demo about [TOPIC] with a placeholder voice, render it, look at the contact sheet yourself, fix overlaps, and write everything you learned into .claude/skills/reels/SKILL.md so next time I only say "reel banao: X".
💡 Pehli baar perfect nahi hoga, normal hai. Contact sheet dekh ke seedha bolo: "captions upar karo", "cards mein zyada bounce", "character bada". Har fix skill file mein save karwa lo.

chatterbox

Chatterbox V3 se Hindi voice (free)

install
python3.12 -m venv .venv-cb && source .venv-cb/bin/activate
pip install chatterbox-tts
clone_cb.py
import re, torch, torchaudio as ta
from chatterbox.mtl_tts import ChatterboxMultilingualTTS

model = ChatterboxMultilingualTTS.from_pretrained(device="mps", t3_model="v3")  # NVIDIA: "cuda"
text = open("script.txt").read().strip()
parts = [s for s in re.split(r"(?<=[।.?!])\s+", text) if s]   # ek sentence ek baar
out = []
for i, s in enumerate(parts):
    torch.manual_seed(42 + i)
    out += [model.generate(s, language_id="hi", audio_prompt_path="me.wav"), torch.zeros(1, int(model.sr * 0.06))]
ta.save("vo.wav", torch.cat(out, dim=1), model.sr)

Dedicated Hindi pack bhi hai: ResembleAI/Chatterbox-Multilingual-hi.

⚠️ Chatterbox har audio mein ek invisible watermark (Resemble Perth) daalta hai, taaki AI voice pehchaani ja sake. Sunai nahi deta, par hai.
voxcpm

VoxCPM2 se clone (free)

install
python3.12 -m venv .venv-vox && source .venv-vox/bin/activate
pip install voxcpm soundfile
clone_vox.py
import soundfile as sf
from voxcpm import VoxCPM

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)
wav = model.generate(
    text=open("script.txt").read().strip(),
    prompt_wav_path="me.wav",                 # tumhari awaaz
    prompt_text=open("me.txt").read().strip(), # jo me.wav mein bola
    cfg_value=2.0, inference_timesteps=10,
)
sf.write("vo.wav", wav, model.tts_model.sample_rate)

README ke hisaab se Python 3.10–3.12, PyTorch 2.5+, CUDA 12+ chahiye. Lamba script ek saath mat do: 2–3 sentences ke chunks banao, ek ajeeb aaye to sirf wahi dobara.
