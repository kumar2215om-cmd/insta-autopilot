Before you start

Honest note

⚠️ These are blueprints, not finished files. You build each workflow in n8n (about 15–45 min per workflow once you know n8n). Salary is ₹0, but the AI brain (OpenAI, Claude or Gemini API) costs a little per run, and some apps (WhatsApp Cloud API, Twilio) have their own small fees. Test everything on demo data first.
Setup

Setup (one time)

  1. n8n: use n8n Cloud (free trial) or self-host it for free with Docker (command below).
  2. Credentials: add these in n8n → Credentials: an AI model (OpenAI, Anthropic or Gemini), Google Sheets, Gmail, Google Calendar, and WhatsApp (Cloud API, or a provider like Interakt or Wati).
  3. One Google Sheet as your mini-CRM: tabs for Leads, Customers, Invoices, Tasks.
  4. The AI step: use the AI Agent or Basic LLM Chain node, with the prompt shown in each blueprint.
Self-host n8n
docker run -it -p 5678:5678 n8nio/n8n
💼 Sales

Sales (1–4)

  1. Lead Finder: Schedule (daily 9 AM) → HTTP Request (Google Maps / Places API: "<category> in <city>") → Split Out → Remove Duplicates → AI: "Score this business 1–10 as a fit for <my offer>; give one line why." → Google Sheets (append to Leads).
  2. Replier: WhatsApp Trigger (new message) → AI Agent with a Sheets tool (FAQ + prices): "Reply in Hinglish in 2 lines, answer from the FAQ, then ask one qualifying question." → WhatsApp Send → Sheets (log).
  3. Call Booker: Sheets Trigger (lead score ≥ 7) → AI: write a short message with a booking link → WhatsApp Send (Cal.com or Calendly link) → Cal.com Trigger (booked) → Sheets update + Gmail confirmation.
  4. Re-order Bot: Schedule (daily) → Sheets (customers whose last order was more than X days ago) → AI: "Friendly re-order reminder mentioning <product>, max 2 lines." → WhatsApp Send.
🎧 Support

Support (5–8)

  1. Receptionist: WhatsApp/Webhook → AI Agent with a Google Calendar tool (check free slots, create event) → WhatsApp confirm → Schedule a reminder 2 hours before.
  2. Call Rescuer: Twilio/Exotel webhook (missed call) → Wait 1 min → WhatsApp Send: "Sorry we missed your call! How can we help?" → Sheets (log the lead).
  3. Inbox Sorter: Gmail Trigger → AI (Text Classifier: lead / support / invoice / spam) → Switch → Gmail Add Label + Slack/WhatsApp ping for urgent mail.
  4. FAQ Bot: Webhook (website chat) or WhatsApp → AI Agent with a vector store (upload your FAQ docs) → reply → hand over to a human if confidence is low.
📣 Marketing

Marketing (9–12)

  1. SEO Writer: Schedule (weekly) → Sheets (keyword list) → AI: "Write a 700-word local SEO page for <service> in <area> with H2s, FAQs and a CTA." → WordPress/Webflow (create draft).
  2. Repurposer: Google Drive Trigger (new video) → transcribe (OpenAI Whisper node) → AI: "Turn this transcript into 5 posts: 1 reel script, 1 carousel, 1 tweet thread, 1 LinkedIn post, 1 caption." → Sheets/Notion (content calendar).
  3. Review Bot: Schedule (hourly) → Google Business Profile API (new reviews) → AI: "Reply warmly, mention their detail, max 40 words; apologise and offer a fix if negative." → post the reply (or send it to you for approval).
  4. Review Asker: Sheets Trigger (order delivered) → Wait 2 days → WhatsApp Send (personal ask + review link).
💰 Finance

Finance (13–16)

  1. Bill Reader: Gmail Trigger (has attachment) → Extract From File (PDF) → AI (Information Extractor: vendor, date, amount, GST, due date) → Sheets (Invoices).
  2. Collector: Schedule (daily) → Sheets (unpaid invoices past their due date) → AI: polite reminder, firmer each time → WhatsApp/Gmail → log the attempt number.
  3. Statement AI: Upload bank statement CSV (Form trigger) → AI: categorise each transaction (rent, ads, salary, software…) → Sheets → monthly summary to Gmail.
  4. GST Clerk: Sheets Trigger (new sales invoice) → Code node (calculate CGST/SGST/IGST) → Sheets (GST register in GSTR-1 format). Have your CA review it before filing.
⚙️ Ops

Ops (17–20)

  1. HR Screener: Form/Gmail (resume) → Extract From File → AI: "Score 1–10 against this JD; list 3 strengths and 2 gaps." → Sheets → notify for scores ≥ 8.
  2. No-show Stop: Calendar Trigger (event in 24h) → WhatsApp "Reply YES to confirm" → Wait for reply → IF no reply after 3h, send a second reminder and alert you.
  3. Deadline Bot: Schedule (8 AM daily) → Sheets/Notion (tasks due within 48h) → AI: write a crisp to-do summary → WhatsApp/Slack to the owner.
  4. Doc Chaser: Sheets (client → missing docs) → Schedule → WhatsApp/Gmail request with an upload link (Drive folder or form) → Drive Trigger (file received) → mark done.
Build order

Build order (recommended)

Start with the ones that make or save money fastest: Call Rescuer (6) → Replier (2) → No-show Stop (18) → Review Asker (12) → Collector (14). Then add the rest.
