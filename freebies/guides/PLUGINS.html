basics

Plugin vs skill: 20 second mein

  • /plugin marketplace add owner/repo → Claude Code ke andar chalao, phir /plugin install name@marketplace.
  • npx skills add owner/repo → terminal mein chalao, skill folder copy ho jaata hai.
  • Hatana ho to: /plugin menu se uninstall, ya ~/.claude/skills/ se folder delete.
💡 Har repo ka licence, last update aur install command hamne 1 Nov 2026 ko khud GitHub pe check kiya. Repos badalte rehte hain, install se pehle README dekh lena.
