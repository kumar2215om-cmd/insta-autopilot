Free software, par zimmedari aapki

Software free hai, par server, setup, updates aur backups ka kharcha aur zimmedari aapki hai. Testing aur chhoti teams ke liye ye bahut paise bachate hain.

Har repo ka GitHub path diya hai; github.com/ ke baad paste karo (ya link pe tap karo).

Shuru karo

Kahan se shuru karein

  1. Pehle laptop pe try karo: Open WebUI + Ollama ya Stirling PDF jaise tools Docker se local chal jaate hain, server ki zaroorat nahi.
  2. Server chahiye to: ek chhota VPS (cloud server) lo, aur us pe Coolify install karo; baaki apps Coolify se deploy karna aasaan hai.
  3. Backups on rakho: database wale tools (Supabase, Dify) ke liye regular backup set karo.
  4. Updates: mahine mein ek baar version update aur security patches check karo.
  5. Licence padho: kuch repos (jaise Dify, ya AGPL wale) commercial ya multi-tenant use pe shartein lagate hain; business mein use se pehle LICENSE file padho.
