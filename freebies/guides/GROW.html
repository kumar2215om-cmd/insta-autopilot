Claude Instagram growth: walkthrough + prompts

Claude ko aapke Instagram se jod ke research, planning aur content ek hi jagah karwana: outliers, 30-day dashboard aur roz ka content.

Pehle padho

Ye walkthrough kya hai

Maine Claude ke saath content bana ke apna Instagram 0 se 6,396 followers tak pahunchaya. Ye walkthrough agla step hai: Claude ko aapke Instagram se jod ke research, planning aur content ek hi jagah karwana.

⚠️ Sach: growth kisi tool se guarantee nahi hoti. Claude plan aur content mein help karta hai; consistency, achhe hooks aur aapka review hi asli farak laate hain. Ootto ek third-party connector hai, iski pricing aur features use karne se pehle khud check karo.
Step 1

Ek baar connect karo

  1. Instagram account Professional (Creator ya Business) hona chahiye.
  2. claude.ai kholo, Customize pe jao, phir Connectors.
  3. Add custom connector dabao.
  4. Name: Ootto. Remote MCP server URL: Ootto ki official website se copy karo (reel mein mcp.ootto.ai/mcp dikhaya tha; official site se confirm karo).
  5. Connect dabao, Instagram se login karo, permissions padh ke Allow.
  6. "Connected" dikhe to setup done. Ye sirf ek baar karna hai.
💡 Custom connectors har Claude plan pe available nahi hote; option na dikhe to apna plan check karo.
Prompts

Prompts (isi order mein)

1 · Outliers dhoondo
Mera niche hai [topic], audience [kaun]. Mere niche ke outliers dhoondo: wo posts jo apne account ke average se 5x ya zyada chal rahe hain, pichhle 30 din mein. Har ek ka hook, format, length aur kyun chala, table mein do. Phir 5 patterns batao jo main copy kar sakta hoon.
2 · 30-day content dashboard
Upar ke outliers aur meri profile ke top posts ke basis pe 30 din ka content dashboard banao. Har din: format (reel/carousel/story), topic, pehle 3 second ka hook, CTA aur comment keyword. Mix rakho: 60% reels, 25% carousels, 15% stories. Table mein do.
3 · Let's start
Let's start. Dashboard ka Day 1 ka content banao: script (Hinglish, 40-50 sec), on-screen text, caption aur hashtags. Post karne se pehle mujhe dikhao.
4 · Apni footage ke saath
Use these: [clips upload]. Day 2 ka script inhi clips ke hisaab se adjust karo aur batao kaun sa clip kahan aayega.

Safety

Safety

  • Kuch bhi bina aapke review ke post ya DM na ho; prompts mein "post mat karna" likho.
  • Permissions dhyan se padho; access hatana ho to Instagram Settings mein Apps and websites se aur Claude mein Connectors se disconnect karo.
  • Bahut zyada automated DMs ya comments se Instagram account restrict kar sakta hai.
