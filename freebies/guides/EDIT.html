ChatGPT video editing: skill + setup

Pehle padho

Kya hoga, kya nahi

Is setup se ChatGPT aapki raw clips aur images se ek edited short video banane ki koshish karta hai: pauses aur filler words cut, captions, zooms aur 9:16 export. Iske liye ChatGPT ka wo plan chahiye jisme file upload aur code/data analysis tool chalta ho.

⚠️ Sach: ChatGPT ka editing simple cuts, captions aur trims ke liye achha hai; heavy motion graphics ya perfect sync ki guarantee nahi hai. Pehle ek chhoti clip (30–60 sec) se test karo, phir lambi videos do.
Skill

Video editing skill (SKILL.md)

Neeche ka poora text copy karke ek file banao SKILL.md. Har baar video edit karwate waqt ise upload karo, ya ChatGPT Project ke instructions mein paste kar do.

SKILL.md
name: video-editing
description: Meri raw clips ko short-form vertical video (Reels/Shorts) mein edit karo, mere style mein.

## Input
- Clips (mp4/mov), images (png/jpg), optional voiceover (mp3/wav)
- STYLE.md (agar ho) — reference videos se seekhe gaye style rules. Ye rules sabse upar.

## Edit rules
1. Har pause > 0.3 sec aur filler words (umm, aaa, matlab, like) cut karo.
2. Pehle 2 second mein sabse strong line ya visual rakho (hook).
3. Captions: bold, 2-3 words at a time, centre se thoda neeche, safe area ke andar. Keyword ek accent colour mein.
4. Har important line pe 110% punch-in zoom, 0.2 sec ease.
5. Har 2-3 sec mein visual change: cut, zoom, B-roll ya image.
6. Background music voice se 18-20 dB neeche; voice hamesha clear.
7. Loudness approx -14 LUFS.
8. End pe 1.5 sec CTA card (jo text main bataun).

## Output
- 1080x1920, 30 fps, H.264 mp4, file name: final_cut.mp4
- Saath mein ek short edit log: kya cut kiya, kitne captions, total length.

## Process
- Pehle plan batao (cut list + timeline), meri "ok" ke baad render karo.
- Kuch possible na ho (jaise koi effect), to saaf bata do aur closest option do.
7 steps

7 steps

  1. ChatGPT kholo. Best hai ek naya Project banao (jaise "Reels Editing"), taaki style aur skill har chat mein yaad rahe.
  2. References daalo. 2–3 pasandida videos ke links do aur neeche wala STYLE prompt bhejo.
  3. Skill add karo. Upar wala SKILL.md file upload karo, ya Project instructions mein paste karo.
  4. Footage taiyaar karo. Clips (sabse achhe takes), images, aur agar ho to voiceover. AI visuals chahiye to kisi image/video tool se bana ke saath rakho.
  5. Sab upload karo. Clips, images, STYLE.md aur SKILL.md ek hi message mein.
  6. Prompt bhejo (neeche wala edit prompt).
  7. Wait karo aur check karo. Time file size par depend karta hai. Edit log padho, video dekho, phir changes maango.
Step 2 · STYLE prompt
In videos ka editing style study karo: [links]. Cut speed, caption style, zooms, transitions, music level aur pacing ke rules nikalo, aur unhe STYLE.md file mein do jo main save kar saku.
💡 Agar ChatGPT Instagram links na khol paaye, to videos download karke upload karo, ya ek connector (jaise Ootto) try karo. STYLE.md download karke rakh lo; ye sirf pehli baar karna hai.
Step 6 · Edit prompt
Meri video-editing skill aur STYLE.md follow karke in clips ko ek 30-45 second ki reel mein edit karo. Hook: [pehli line]. CTA card: "Comment EDIT". Pehle cut list dikhao, phir render karo.
Changes

Changes maangne ke prompts

  • "Intro 2 second chhota karo, pehli line seedha shuru ho."
  • "Captions bade karo aur keyword green mein."
  • "Beech ke 5 second slow lag rahe hain, wahan B-roll daalo."
  • "Music thoda kam karo, voice aur clear."
  • "Same edit 1:1 square mein bhi export karo."
💡 Ek baar mein ek change maango; 3–4 changes ek saath dene se galti badhti hai. Achha result mile to bolo "ye style STYLE.md mein update kar do", agli video aur better aayegi. Final export khud phone pe dekh ke check karo: captions safe area mein hain, audio sync sahi hai.
