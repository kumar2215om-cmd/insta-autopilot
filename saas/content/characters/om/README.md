# Om's carousel character: all 90 poses

Every pose from Om's three character sheets (`source-sheet1/2/3.webp`), cut out by detecting each figure (heads and
feet are complete, unlike the grid cut in `../om-v1`). Transparent PNGs, white background removed.

- `characters.json`: pose name → file, emotion, tags, framing (bust / half / full / sitting) and facing direction.
- `roles.json`: which tags fit which slide role (hook, explain, tool, steps, tip, mistake, result, easy, cta).
- Some poses include a prop with white faces (a cube seat, a pillar); keep them or skip as needed.
- Low resolution (about 150–300 px): upscale before use, and replace the most-used poses with high-res renders.
