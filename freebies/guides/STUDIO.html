6 steps

Bina terminal ke, 6 steps

  1. Claude desktop app kholo (claude.com/download) → Code tab.
  2. Zip unzip karo, folder ka naam rakho AI Video Editor. Har reel isi folder mein banegi.
  3. New session → Local → ye folder select karo.
  4. Claude ko bolo: setup check karo. Wo Node, ffmpeg, Python check karta hai, baaki khud install karta hai.
  5. Bolo: reel banao: 3 AI tools jo students ka time bachate hain. Script aayegi, tum approve karo, phir voice file do.
  6. Editor ki tarah bolo: hook aur punchy karo, captions bade karo, beat 3 fast karo. Wo fix karke dobara render karta hai.
💡 Pehli reel se pehle studio/src/brand.ts mein apna handle daal do (ya Claude ko bolo), wahi watermark mein aayega.

honest notes

Ye jaan lo

  • Pehli baar setup mein internet + ~2 GB disk lagta hai (Remotion + Whisper model).
  • Chahiye: Node.js 18+, ffmpeg, Python 3.9+. setup check karo batata hai kya missing hai.
  • Remotion ka apna licence hai: individuals aur ≤3 logon ki team ke liye free; badi company ho to remotion.dev/license.
  • Voice service ki commercial terms khud check karo.
  • Reel ke facts ki zimmedari tumhari. Skill unverified claims flag karta hai.
  • Remotion ka browser na chale to BROWSER_EXECUTABLE mein apna Chrome path do (README mein hai).
