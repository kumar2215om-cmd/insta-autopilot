Plan 100 researched reels, edit them as one journey

Before you start

Honest note

⚠️ Claude plans and scripts the reels for you. It doesn't post them. Check every script and every video yourself before posting.
Part 1

100 reel scripts, built from research (not random)

What you need

  • A Claude account (Pro or higher is best for long sessions)
  • Claude Code, if you want to install skills as a plugin
  • Two free, open-source skill packs (MIT): claude-content-skills (research, hooks and scripting skills) and claude-virality-skill (patterns from what actually went viral)

Install. In Claude Code, run:

Claude Code
/plugin marketplace add Ootto-AI/claude-content-skills
/plugin marketplace add Ootto-AI/claude-virality-skill

Then open /plugin and install both. In the Claude app, you can instead download the skill folders from GitHub and upload them under Settings → Capabilities → Skills.

Inputs

The 4 research inputs (same as in the reel)

  1. Your niche: tell Claude your niche, audience and language, e.g. "AI tools for Indian creators, Hinglish". Ask it to search what's trending this month.
  2. Competitor trends: paste 3–5 competitor handles and their top reel topics or hooks. Ask Claude to find the common patterns.
  3. Your own best reels: paste the titles, hooks and views of your top 5–10 reels. Claude finds what your audience responds to.
  4. Hooks + language from the internet: ask Claude to collect real phrases people use (YouTube comments, Reddit, X) so your scripts sound like your audience.
The prompt
Use the content research + virality skills.
My niche: <niche>. Audience: <who>. Language: Hinglish.
Competitors: <handles + their top topics>.
My best reels: <hook – views> x 5.
Step 1: research trends + patterns and show me a summary.
Step 2: plan 100 reels as a table: # | topic | hook (first 3 sec) | angle | CTA keyword.
Step 3: write full scripts for the first 10 (max 45 sec each).
💡 Work in batches of 10–20 scripts so quality stays high, then edit them in your own voice.
Part 2

Edit like this reel (one camera, no cuts)

This reel was built with Claude Code + Remotion (code-based video editing).

  1. Install Node.js, then run npx create-video@latest to create a Remotion project.
  2. Open the folder in Claude Code.
  3. Give Claude your voiceover file and script, then use the prompt below.
  4. Preview with npx remotion studio, ask Claude for fixes, then render with npx remotion render.
Step 3 · Prompt
Build a 9:16 reel in Remotion from this voiceover.
Layout: put every scene as a "station" on one big canvas (3x3 grid).
Camera: ONE continuous camera that flies from station to station, no cuts.
At the end, zoom out to show the whole journey, then land on the CTA.
Add word-by-word captions synced to the voice, plus light SFX on each move.
💡 Why it works: a seamless camera turns the reel into one story instead of separate slides, so viewers keep watching to see where the camera goes next.
Tips

Tips

  • Rendering takes a few minutes per reel, so batch it.
  • Keep reels under 50 seconds.
  • Always review the facts and numbers before posting.
