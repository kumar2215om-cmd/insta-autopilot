4 Claude Code plugins to save tokens

Thanks for commenting TOKENS! The 4 plugins from Part 3: Ponytail, OmniRoute, Graphify and Agent Skills. Run the commands inside Claude Code unless noted.

Before you start

Honest note

⚠️ Token savings depend heavily on your project. Independent tests show much smaller savings than the marketing numbers, so try them on your own codebase. Repos change often, so check each README for the latest install steps.
💡 Part 1 = SENIOR guide, Part 2 = CODING guide.
1 · Ponytail

1 · Ponytail

Pushes Claude to write less, simpler code (a YAGNI-style "do we really need this?" ladder), so you spend fewer tokens and get less bloat.

Install (send as two separate messages)
/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
💡 There's a known Windows slowdown issue. Check the repo if messages stall.
2 · OmniRoute

2 · OmniRoute

An open-source AI gateway that routes Claude Code to many free-tier providers (Gemini, Groq, Qwen, DeepSeek…). When one limit runs out, it falls back to the next model automatically.

Find it on GitHub by searching "OmniRoute" and follow its setup (it runs a local endpoint that Claude Code points to).

⚠️ Privacy: your prompts and code go to third-party providers, each with their own terms. Don't use it for client or confidential code. Free-tier limits also change often.
3 · Graphify

3 · Graphify

Turns your whole codebase into a knowledge graph, so the agent can query structure instead of re-reading files again and again. It helps most on large repos (100+ files).

MIT licensed. Search GitHub for "graphify" Claude Code and follow the README install.

💡 Rebuild the graph after big refactors (it can go stale), and check the README for Claude Code version compatibility.
4 · Agent Skills

4 · Agent Skills (by Addy Osmani)

A skill pack that makes Claude work like a senior engineer, with dedicated skills for spec, plan, build, test, review and ship that activate at the right stage.

Repo: github.com/addyosmani/agent-skills (MIT)

Install
/plugin marketplace add addyosmani/agent-skills
/plugin install agent-skills@addy-agent-skills

Commands: /spec /plan /build /test /review /ship

Free tips

Free tips that also save tokens

  • Keep a short, clear CLAUDE.md (project rules) so Claude doesn't re-discover things.
  • Use /clear between unrelated tasks.
  • Ask for plans first, then code.
