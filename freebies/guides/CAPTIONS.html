idea

Words script se, time awaaz se

Zyadatar caption tools pehle AI se "kya bola" sunte hain, phir galtiyan theek karni padti hain: video ban jaata hai वीडियो, "keyword" ban jaata hai कीवर्ड. Hum ulta karte hain:

  • Words tumhari script se aate hain, isliye spelling kabhi galat nahi hoti.
  • Time awaaz se aata hai: jahan tum bolte ho aur jahan rukte ho.
  • AI model zero: na download, na upload, na API key. Hindi, Hinglish, English sab same.

Hamara test: 3 asli reels, 108 caption lines → 94% lines 0.15 second ke andar sahi start.

kaise

Andar kya hota hai (simple)

  1. Pauses dhundo: awaaz ki energy har 10 ms naapi jaati hai. Jahan awaaz hai = bolna, jahan nahi = pause.
  2. Lines jodo: script ki har line ko ek ya zyada speech chunks milte hain. Kaunsa chunk kis line ka hai, ye aise chuna jaata hai ki line ka audio time uske text ki lambai se match kare, aur line wahin toote jahan lamba pause hai.
  3. Words baanto: line ke andar har word ko utna time jitna use bolne mein lagta hai ("subscription" ko "ye" se zyada).
💡 Numbers aur acronyms bolne mein lambe hote hain ("$10" = "ten dollar"). Inko spoken.json mein likho, timing aur sahi ho jaati hai.

script

Script kaise likhein

script.txt
एक और *AI_subscription लेने से पहले…
ये देख लो।
इसका नाम है *ChatLLM… ^Abacus_AI का।
  • Ek line = ek saans. Jahan voice rukti hai, wahan nayi line.
  • Script wahi jo bola gaya: ElevenLabs ne kuch badla ho to script bhi badlo.
  • *word = rose highlight, ^word = blue highlight, _ se naam jodo (Abacus_AI).
  • Sirf voice file do, music wali nahi.

claude code

Khud nahi karna? Claude se karwao

Claude Code prompt
Sync my reel captions with caption-sync-kit (local, no AI model).
Files: voice = [public/vo.wav], script = [paste or path], kit = [path to caption-sync-kit].
1. Write script.txt: one line per phrase I say in one breath. Keep my exact words; mark 1–2 keywords per line with * or ^; join names with _.
2. Write spoken.json for numbers/acronyms (e.g. "$10": "ten dollar").
3. Run captions_sync.py → public/captions.json and read the report.
4. For each "⚠ check" line, fix the line breaks in script.txt where the voice really pauses and re-run. Never invent words.
5. Add Captions.tsx with my brand colours inside Instagram safe zones.
6. Render 3 stills and check them yourself before the full render.
honest

Kab kaam nahi karega

  • Script nahi hai (live talk, podcast): pehle kisi Whisper tool se text nikaalo, phir lines banao.
  • Music/noise ke saath voice: pauses nahi milte. Clean voice file do.
  • Bina ruke lambi line: line ke andar time word-length se baanta jaata hai, isliye bahut fast bolne pe ek-do word thode aage-peeche ho sakte hain. Lambi line ko 2 mein todo.
