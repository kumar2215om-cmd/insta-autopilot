Claude Content Skills kya hai

Tumne INSTAGRAM comment kiya tha, to ye raha poora setup. 🙌 Claude Content Skills ek free GitHub repo hai: github.com/Ootto-AI/claude-content-skills. Isme 50+ Claude skills hain (abhi 54 folders), aur har skill ek kaam karti hai: hooks, scripts, carousels, captions, comment replies, content calendar aur content research.

⚠️ Honest note: Repo Ootto ne banaya hai, MIT license, aur bilkul free hai. README mein unke paid autopilot ka promotion bhi hai; skills use karne ke liye wo zaroori nahi. Ye Claude Code mein chalti hain (normal claude.ai chat mein link paste karne se install nahi hoti). Skills text/plan banati hain; voiceover, video render aur auto-DM ke liye alag tools lagte hain (ElevenLabs, Remotion/CapCut, ManyChat).
Install

Install (2 minute)

Option A: Claude Code plugin (recommended). Claude Code kholo aur ye 2 commands ek-ek karke paste karo:

Claude Code
/plugin marketplace add Ootto-AI/claude-content-skills
/plugin install claude-content-skills@ootto-content-skills

Option B: Manual (macOS / Linux terminal):

Terminal
git clone --depth 1 https://github.com/Ootto-AI/claude-content-skills.git
bash claude-content-skills/install.sh

Dono tarike skills ko ~/.claude/skills/ mein daal dete hain. Claude Code restart karo, aur skills ready hain.

💡 Option C: Claude Code nahi hai? Har skill ek plain prompt hai. GitHub pe skill ki SKILL.md file kholo, prompt copy karo, aur claude.ai mein apne idea ke saath paste kar do.
