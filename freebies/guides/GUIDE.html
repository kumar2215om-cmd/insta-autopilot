4 steps, idea se leads tak

Tumne GUIDE comment kiya tha, to ye raha poora process. 🙌 Mere page ki reels isi tarah banti hain:

  1. Study: viral reel ko frame by frame samjho
  2. Write: original hook + script
  3. Build: poori reel (music, captions, animations, voiceover)
  4. Leads: comment karne walon ko auto-DM
⚠️ Honest note: Voiceover ElevenLabs se banta hai; Claude script likhta hai aur voice ko reel mein jodta hai. Auto-DM ke liye ek alag tool chahiye (jaise ManyChat); Claude akela Instagram pe DM nahi bhejta. Viral reel ko copy mat karo: uska structure seekho (hook, pacing, beats), content apna banao.

Step 1

Study: viral reel ko samjho

Viral reel download karo (ya uske screenshots, har 0.5 sec pe ek) aur Claude ko do, saath mein ye prompt:

Study prompt
Ye ek viral reel hai. Isko frame by frame study karo aur batao:
1. Hook: pehle 1-2 second mein kya dikhta aur bola jaata hai?
2. Beats: har scene ka time, on-screen text, visual, animation.
3. Pacing: kitne second pe cut hota hai, kab SFX/zoom aata hai.
4. CTA: end mein kya keyword aur kya offer hai.
5. Ye reel viral kyun hui, 3 points mein.
Step 2

Write: original hook + script

Script prompt
Is structure ko use karke MERE niche ke liye ek ORIGINAL reel script likho.
Niche: [apna niche]  |  Language: Hinglish  |  Length: 30-45 sec
Same beats aur order rakho, lekin content, examples aur claims mere apne ho.
Hook pehle 1 second mein. Har line ke saath on-screen text bhi do.
End mein CTA: Comment "[KEYWORD]".
Koi bhi claim jo verify nahi ho sakta, use mark karo.
Step 3

Build: poori reel

  1. Script ko ElevenLabs mein paste karo, Hinglish voice choose karo, aur MP3 download karo.
  2. Ek folder banao, usme MP3 daalo, aur Claude Code kholo.
  3. Neeche wala prompt do.
  4. Stills check karo, jo cluttered lage use theek karwao, phir render karwao.
  5. Final MP3/MP4 ki loudness Instagram ke liye -14 LUFS rakho, aur lambe pauses kaat do (reel 50 sec se kam).
Claude Code prompt
Remotion project banao: 1080x1920, 30fps.
vo.mp3 mera voiceover hai. Har line ka timing nikaalo aur uske hisaab se scenes banao:
- Har beat ka headline upar (bada, clean), ek main visual beech mein
- Karaoke caption pill neeche (max 5 words)
- Spring pop-ins, 3D whip transitions, har click/pop pe SFX
- Halka lo-fi music voice ke neeche
Mera brand: cream background, cerulean + pink accents.
Render se pehle key frames ki stills dikhao, taaki main check kar sakun.
Step 4

Leads: comment → auto DM

  1. ManyChat (ya koi Instagram auto-DM tool) ko apne Instagram professional account se connect karo.
  2. Ek automation banao: trigger = comment mein keyword (jaise GUIDE), aur action = DM mein tumhara doc/link.
  3. Reel ke caption aur end-screen pe wahi keyword likho.
  4. DM ka message Claude se likhwao: chhota, friendly, aur ek clear link.
Checklist

Checklist

  • Viral reel study ki (hook, beats, pacing, CTA)
  • Original script likhi, copy nahi ki
  • ElevenLabs voiceover ready hai
  • Claude Code + Remotion se reel build ki, stills check kiye
  • Reel 50 sec se kam aur -14 LUFS par hai
  • Keyword auto-DM test kiya (khud comment karke)
