The prompt

The prompt

Paste into Claude Code
Audit this app for 5 cost and security risks. For each: find where it applies, explain the risk in one line, implement the fix, and list manual steps I must do in dashboards.

1. TRAFFIC / BILL SHOCK: Protect against DDoS and bandwidth spikes. Put the site behind a CDN/WAF (e.g. Cloudflare), add rate limiting on API routes, cache static assets, and tell me exactly which hosting setting enables spend caps or alerts (and which ones only alert).

2. ACCESSIBILITY: Make the whole site keyboard-usable (visible focus, logical tab order, no keyboard traps), add meaningful alt text to all images, add labels to form inputs, check color contrast, and add an accessibility statement page. Run an automated check (axe / Lighthouse) and fix the issues.

3. SUPABASE SECURITY: Find every table. Enable Row Level Security on ALL of them and write least-privilege policies (users can only read and write their own rows). Make sure the service_role key is never in client code (only the anon key). List any table that is still publicly readable.

4. SMS / TCPA: Find any code that sends SMS or WhatsApp marketing. Require explicit opt-in (unchecked checkbox plus consent text and a timestamp stored in the DB), support STOP / opt-out, and block sends to anyone without recorded consent.

5. RUNAWAY FUNCTIONS: Find cloud functions, triggers, webhooks or cron jobs that could call themselves or loop (e.g. a function that updates the same record that triggers it). Add recursion guards, idempotency checks, max-retry limits and timeouts, and set max instances / concurrency limits. Tell me how to set a hard budget cap or kill switch on my cloud provider.

At the end, give a table: item | status (fixed / manual) | files changed | manual steps.
Manual

Manual steps the code can't do

  • Enable spend limits on your host or cloud. Note that budget alerts only notify: set max instances or a hard cap where available.
  • In Supabase, open Advisors → Security and fix every warning.
  • Put your domain behind Cloudflare (free plan) for DDoS protection.
  • Re-test with a keyboard only (Tab / Shift+Tab / Enter).
Self-check

60-second self-check

  • Supabase: does any table show RLS disabled? Fix it.
  • Open your site and press Tab repeatedly. Can you reach every button?
  • Search your code for service_role. It must never be in frontend code.
